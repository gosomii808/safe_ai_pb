## 🛠️ 포트폴리오 더미데이터 등록 방법

1. **포트폴리오 관리 페이지**로 이동합니다.
2. **"종목 추가"** 버튼을 클릭합니다.
3. 위의 시나리오 중 하나를 선택하여 시장(KOSPI / NASDAQ), 티커, 수량(주수), 평균 매수가를 차례로 입력 후 **저장**합니다.
